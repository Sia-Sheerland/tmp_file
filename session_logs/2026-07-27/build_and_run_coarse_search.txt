# ─────────────────────────────────────────────
# 3. 这次改动的三个优化
# ─────────────────────────────────────────────
#
# (1) try_3_temp4 风格 IO（AsyncIO 新加 MultiReadInPlaceImpl）
#     - 给每个 doc 单独 posix_memalign 对齐 buffer
#     - 单次 io_submit 提交全部 2322 个读请求（不切 400 的 chunk）
#     - 单次 io_getevents 等待全部完成
#     - Compute 直接从 per-doc buffer 读数据（没有 memcpy 到 all_codes）
#
# (2) ComputeDist 内联 SIMD
#     - 把 FP32ComputeIP 函数指针调用改成 inline 标量循环
#     - 编译器 -O3 -march=native 自动向量化到 AVX2/AVX-512
#     - 消除 2M+ 次函数指针调用开销
#
# (3) 恢复 O_DIRECT
#     - 配合 #1 达到硬件极限
#     - 之前 page cache 实验效果不明显，回退

# ─────────────────────────────────────────────
# 4. 预期效果
# ─────────────────────────────────────────────
#
# 基线：/tmp/simq_output_coarse_flat_array.log（之前 async_io 版本）
#
# | 指标         | 基线        | 预期         |

# 如果 mv_compute 真的降到 2ms，说明函数指针开销被消除了
